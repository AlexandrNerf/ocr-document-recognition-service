# OCR Document Recognition Service - Frontend

Фронтенд-приложение для документации и тестирования сервиса распознавания текста OCR (Optical Character Recognition) Document Recognition Service.

## Описание проекта

Это веб-приложение предоставляет документацию и интерфейс для работы с OCR сервисом, который использует технологии машинного обучения на базе PyTorch Lightning и Hydra для автоматического распознавания текста на изображениях и PDF-документах.

## Основные возможности

- 📚 **Документация проекта** — обзор сервиса, архитектуры и возможностей
- 🔬 **Научные статьи** — коллекция ключевых исследований в области OCR
- 🚀 **Быстрый старт** — руководство по установке и запуску backend-сервиса
- 🧪 **Тестирование API** — интерактивная страница для загрузки файлов и тестирования распознавания текста
- 📖 **API Документация** — встроенная Swagger UI документация для REST API

## Технологический стек

- **React 19** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик и dev-сервер
- **React Router** — маршрутизация
- **Material-UI (MUI)** — UI компоненты
- **Axios** — HTTP клиент
- **Swagger UI** — документация API
- **Formik & Yup** — работа с формами
- **Fuse.js** — поиск по документации

## Установка

### Требования

- Node.js (версия 18 или выше)
- npm или yarn

### Шаги установки

1. Зайдите в `core` папку проекта и запустите из окружения poetry бэкенд сервис:

```bash
python app.py
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта (опционально):
```env
VITE_API_BASE=http://localhost:8000
```

Если переменная окружения не задана, по умолчанию используется `http://localhost:8000`.

## Запуск

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173` (или другому порту, если 5173 занят).

### Сборка для production

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist/`.

### Предпросмотр production сборки

```bash
npm run preview
```

### Линтинг

```bash
npm run lint
```

## Маршруты приложения

- `/` — перенаправление на `/overview`
- `/overview` — обзор проекта и описание OCR сервиса
- `/research` — коллекция научных статей по теме OCR
- `/quickstart` — руководство по установке и запуску backend
- `/test-api` — интерактивная страница для тестирования OCR API
- `/api` — встроенная Swagger UI документация API

## Основные функции

### Тестирование OCR API

Страница `/test-api` позволяет:
- Загружать изображения (JPEG, JPG, PNG) и PDF-документы
- Отправлять файлы на обработку в OCR сервис
- Отслеживать статус обработки в реальном времени
- Просматривать результаты распознавания с визуализацией

### API Документация

Страница `/api` интегрирует Swagger UI для:
- Просмотра всех доступных эндпоинтов API
- Интерактивного тестирования API запросов
- Просмотра схем данных и моделей

## Поддерживаемые форматы файлов

- Изображения: JPEG, JPG, PNG
- Документы: PDF

Максимальный размер файла: 10MB

## Поддерживаемые языки OCR

- Русский
- Английский
- Казахский
