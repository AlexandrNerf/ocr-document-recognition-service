# Структура пайплайнов и датафлоу

Всего на данный момент существует 9 пайплайнов и один общий датафлоу для всех них.
Структура общих шагов описана в `defaults`

## Датафлоу 

Главным механизмом хранения данных является ведением по всему пайплайну словаря `self._data`, описанного в пайплайне и `run.py`.

Данный словарь хранит обновляемые структуры данных с каждого шага.

Изначально `data` пуста, и обновляется с каждым пайлпайном при помощи метода `Pipeline.run()`.

## Таблица со структурой пайплайна

| Пайплайн | Описание действия| Принимает данные | Отдаёт (+)/модифицирует (*) данные | 
|-|-|-|-|
| loader | Загружает изображения из сервиса или локально, парсит pdf файлы если такие есть | `None/image_path/base_64_image` | + `images: list[np.array]`|
| preprocessor | Предварительно обрабатывает изображения | `images: list[np.array]` | * `images: list[np.array]` |
| page_detector | Распознаёт страницу текста на изображении и кропает её, используя | `images: list[np.array]` | + `crop_images: list[np.array]` |
| doc_unwrapper | Делает выравнивание документа на основе результатов поиска страницы | * `crop_images: list[np.array]` |
| detector | Распознаёт боксы текста на изображении | `crop_images: list[np.array]` | + `detections: list[Predictions]` |
| postprocessor | Форматирует предикты из детектора в прямоугольный формат, сортирует боксы по правилу чтения слева-направо, сверху-вниз. Возвращает пост-детекции с кропами каждого слова | `crop_images: list[np.array]`, `detections: list[Predictions]` | + `post_detections: list[Predictions]` |
| recognizer | Распознаёт текст на изображении | `post_detections: list[Predictions]` | + `predictions: list[Predictions]`|
| layout_creator | Распознаёт структуру документа, парсит изображения и создаёт базовую структуру документа для последующего создания json структуры | `crop_images: list[np.array]`, `predictions: list[Predictions]` | + `documents: list[Document]` |
| visualizer | Визуализирует результат работы модели и сохраняет необходимые результаты | `data: dict` | `None` |
