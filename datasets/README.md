# Датасеты для моделинга OCR и детекции

Всего для OCR модели сейчас используется 7 датасетов.

## Список использованных датасетов:

**Важно:** Все датасеты находятся в открытом доступе и не требуют специальной лицензии.

| Название датасета | Ссылка | Размер | Печать / Рукопись | Язык | Формат | Требуется HNM | Рекомендовано для | Комментарий |
|-------------------|--------|--------|-------------------|-------|---------|--------------|-------------------|-------------|
| DDI (DistortedDocumentImage-100) | [GitHub – DDI-100](https://github.com/machine-intelligence-laboratory/DDI-100/tree/master/dataset) | 54k | Печатный | Русский | Сканы | Нет | Pretrain / Robustness | Качество выше среднего, иногда встречаются плохие сэмплы |
| GNHK | [GitHub – GNHK](https://github.com/GoodNotes/GNHK-dataset) | ~31k | Рукописный | Английский | Фото (in-wild) | Да | Finetune (in-wild) | Качество выше среднего, много спецсимволов — требуется очистка |
| IAT (IAM-line) | [HuggingFace – IAM-line](https://huggingface.co/datasets/Teklia/IAM-line) | 49k | Рукописный | Английский | Сканы | Да | Finetune | Проблемы с разметкой после эвристического нарезания слов |
| KOTHD | [GitHub – KOHTD](https://github.com/abdoelsayed2016/KOHTD) | ~115k | Рукописный | Казахский | Сканы | Нет | Pretrain / Low-resource | Высокое качество, проблемные сэмплы не обнаружены |

| SynthRu (synthetic_hkr) | [HuggingFace – synthetic_hkr](https://huggingface.co/datasets/nastyboget/synthetic_hkr/tree/main) | 300k | Рукописный | Русский | Синтетика | Нет | Pretrain | Длинные примеры, может путать модель, рассчитанную на одно слово |

## Версионирование

0) Неактуальные датасеты - `v1` (содержал в себе датасеты 1, 4, 5, 6), v2 (датасеты 1-7)

1) На данный момент актуальна версия датасета `v3`, которая содержит все датасеты.

Основное версионирование датасетов будет происходить по ключевым изменениям. В ключевые изменения относим:

* Добавление/удаление некоторого количества данных из датасета (пока мы берём не всё, ибо некоторые датасеты очень большие)
* Добавление/удаление нового датасета или нескольких датасетов
* Полную предобработку всего OCR датасета с помощью эвристики (например, фильтрации и т.д.), которая меняет пайплайн взаимодействия с моделингом (например, для реализации нового вокаба потребуется новая сортировка, может потребоваться полный пересбор датасетов)

В минорные и ответвления относим вырезки датасетов, фильтрацию одного конкретного датасета.

Также локально храним датасеты для каждого отдельного набора данных (в формате `ocr_<dataset_name>.parquet`). Это промежуточный шаг, необходимый для сохранения всех базовых состояний датасета (без предобработок)

### Текущая актуальная версия 
Для первого обучения используем уменьшенную сбалансированную версию актуального датасета `v3` - `ocr_dataset_v3_hnm.parquet`. 

Данный датасет содержит в себе 890 тысяч примеров.

## Скачивание датасетов

Все датасеты хранятся в репозитории hugging_face и доступны через простой запуск dvc

Сам датасет скачиваем через:

```bash
dvc get https://huggingface.co/NerfmanOriginal/OCR-data-900k ocr_dataset.zip # Архив с изображениями и лейблами
dvc get https://huggingface.co/NerfmanOriginal/OCR-data-900k <НАЗВАНИЕ ДАТАСЕТА>.parquet # Сам датасет в формате таблицы
```

**Важно**: этот способ подтянет датасет полностью, со всеми изображениями (около 12 гб памяти сам архив, на распаковку ещё 12).

Список актуальных имён датасетов, которые можно стянуть:

| Версия датасета | Название датасета для стягивания | Описание |
|-|-|-|
| **v3_hnm** (Рекомендуется) |`ocr_dataset_v3_hnm.parquet` | Датасет v3, на котором был проведён **hard negative mining**. Очищенный вариант, около 800к примеров |
| **v3** |`ocr_dataset_v3_cut.parquet` | Базовый датасет v3, вырезка под длину строки 32, размер 900к+ |
| **v2** |`ocr_dataset_v2.parquet` | Стандартный датасет v2 с размером около 800к, без включения HWCYR датасета |
| **v2_50k** | `ocr_dataset_v2_50k.parquet`| Небольшая подвыборка из версии 2 для тестирования и пробных запусков. Содержит по 50к примеров для каждого датасета | 


Если был скачан датасет с изображениями (`ocr_dataset.zip`), необходимо распаковать данные любым удобным образом. Можно сделать просто 7z или unzip.

Конечный результат - папка `ocr_dataset/` cо всеми изображениями и файл `.parquet` с аннотациями.

### Формат аннотаций

Аннотации хранятся в `.parquet` файлах и содержат несколько колонок - `image_path`, `text`, `source`. 
Они отвечают за путь до файла, текст ground_true и источник датасета (чтобы быстро ориентироваться в том, из какого источника это взято)

### Форматирование датасетов и фильтрации

На данный момент тетрадь для предобработки датасетов в разработке.

Планируемые для реализации элементы:

* Фильтрация всех данных по длине выходного окна.
* Фильтрация или замена всех символов, не попадающих в вокаб.
* Отсеивание плохих результатов по Hard Negative Mining.
* Возможность выбирать желаемый размер каждого набора данных при вхождении в итоговый датасет.

**Важно:** все эти обработки пока планируется реализовать для файлов с отдельными наборами данных.
